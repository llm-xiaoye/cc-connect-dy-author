# 技能设计与保留的行为

## 职责与渐进式披露

`SKILL.md` 定义触发、主流程和不能放宽的边界；`references/workflow.md` 定义队列操作；知识笔记、面试题与恢复细节分别放在对应 references 中。README 面向下载者安装，不要求每条作品重复加载整份文档。

确定性部分由脚本完成：链接/作者绑定、分页、材料提取、去重、检查点、草稿校验和事务提交。当前 Agent 负责完整材料的语义提炼和题目归并。流程不创建新的模型子会话、定时任务或隐式全局选择。

## 兼容的行为合同

- 当前显式 `/dy-author` 才授权作者全量；普通分享、历史输入、旧队列都不替代当前授权。
- 视频和图文保留原材料校验；长文字文章保留“暂不支持”。未完整的列表保留原因，不能升级为完整。
- `aweme_id` 全库去重；已有笔记不被重新下载改写。作者文档用 sec_uid 标识，标记外内容保留。
- 每批十条、逐条 commit，后续失败不回滚成功；草稿存在不等于已提交。
- 面试类写知识层和题库层，其他作品不写题库；补录只补题目，不改原笔记。
- 通知只发当前明确绑定会话，写前持久记录发送尝试，不因超时自动重发。

## 本次公开化变更

核心的作者分页、下载、转写、OCR、去重、知识/题库写入与事务算法保留。仅将私有路径换成下载者配置；通知路径从本地配置读取；安装专属测试改为可移植安装测试。`scripts/configure.py` 与 `scripts/doctor.py` 是安装工具，不参与生产导入算法。

知识库中的工程化与反模式资料用于检查职责、状态可见性、显式输入和按需加载；这些私人资料及原文未包含在仓库。测试与验证范围以 [VALIDATION.md](../VALIDATION.md) 为准，不将离线回归称为真实抖音端到端验证。
